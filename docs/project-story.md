# ORHEX: continuity you can verify

People repeat the same context to every new assistant. ORHEX explores a more continuous alternative: a personal workspace where users choose what to remember, retrieve that context later through Walrus, and inspect live public Sui signals through Tatum.

The central product decision is to make the evidence visible. A submitted memory stays pending until Walrus confirms its write; retrieval shows the records Walrus returns; Sui balances and activity identify Tatum as their source. When a provider is unconfigured or unavailable, ORHEX says so instead of filling the dashboard with demo data.

The first submission is intentionally narrow: establish a polished, private-by-design dashboard, then demonstrate the real memory round trip and a read-only blockchain lookup. No seed phrase, signing key, or transaction approval is required from the user.
